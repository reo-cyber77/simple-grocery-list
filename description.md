🛒 Project: Simple Grocery List
🎯 Concept
A program where the user can:
•	Add items to a grocery list 
•	View the list 
•	Remove items 
________________________________________
📌 Instructions
1.	Create an empty list to store grocery items 
2.	Show a simple menu: 
o	Add item 
o	View items 
o	Remove item 
o	Exit 
3.	Add item 
o	Ask user for item name 
o	Add it to the list 
4.	View items 
o	Display all items in the list 
5.	Remove item 
o	Ask user which item to remove 
o	Delete it from the list 
6.	Repeat until user exits 
________________________________________
